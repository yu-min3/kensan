## 3. コンテキスト管理（DB管理方式）

### 3.1 なぜDBで管理するか

| 方式 | メリット | デメリット |
|------|---------|-----------|
| YAML (ファイル) | バージョン管理容易 | デプロイ必要、A/Bテスト困難 |
| **DB管理** | 動的変更可能、A/Bテスト容易、自動学習対応 | バージョン管理は別途必要 |

### 3.2 コンテキストテーブル設計

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         ai_contexts テーブル                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  id                 UUID PRIMARY KEY                                        │
│  name               VARCHAR(100)        -- "morning_advice_v2"              │
│  situation          VARCHAR(50)         -- "morning", "evening", etc        │
│  version            VARCHAR(20)         -- "2.1.0"                          │
│  is_active          BOOLEAN             -- 現在有効かどうか                 │
│  is_default         BOOLEAN             -- デフォルトコンテキストか         │
│                                                                             │
│  ─── プロンプト設定 ───                                                     │
│  system_prompt      TEXT                -- システムプロンプト本文           │
│  allowed_tools      TEXT[]              -- 許可ツール一覧                   │
│  max_turns          INTEGER             -- 最大ターン数                     │
│  temperature        FLOAT               -- 温度パラメータ                   │
│                                                                             │
│  ─── A/Bテスト用 ───                                                        │
│  experiment_id      UUID                -- 実験ID（NULL=本番）              │
│  traffic_weight     INTEGER             -- トラフィック比率（0-100）        │
│                                                                             │
│  ─── メタデータ ───                                                         │
│  description        TEXT                -- 説明                             │
│  created_by         UUID                -- 作成者                           │
│  created_at         TIMESTAMPTZ                                             │
│  updated_at         TIMESTAMPTZ                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

インデックス:
- idx_ai_contexts_situation_active ON (situation) WHERE is_active = true
- idx_ai_contexts_experiment ON (experiment_id) WHERE experiment_id IS NOT NULL
```

### 5.3 分析クエリ例

```sql
-- シチュエーション別の満足度
SELECT
    situation,
    COUNT(*) as total_sessions,
    ROUND(AVG(rating), 2) as avg_rating,
    COUNT(*) FILTER (WHERE rating >= 4) as satisfied_count
FROM ai_interactions
WHERE rating IS NOT NULL
  AND created_at >= NOW() - INTERVAL '30 days'
GROUP BY situation
ORDER BY avg_rating DESC;

-- コンテキストバージョン比較（A/Bテスト）
SELECT
    c.name as context_name,
    c.version,
    c.experiment_id,
    COUNT(i.id) as sessions,
    ROUND(AVG(i.rating), 2) as avg_rating,
    ROUND(AVG(i.total_latency_ms), 0) as avg_latency_ms
FROM ai_interactions i
JOIN ai_contexts c ON i.context_id = c.id
WHERE c.experiment_id IS NOT NULL
  AND i.created_at >= NOW() - INTERVAL '7 days'
GROUP BY c.id, c.name, c.version, c.experiment_id
ORDER BY c.experiment_id, avg_rating DESC;

-- 低評価インタラクションの詳細
SELECT
    id,
    situation,
    rating,
    LEFT(user_input, 100) as user_input_excerpt,
    LEFT(ai_output, 100) as ai_output_excerpt,
    feedback,
    created_at
FROM ai_interactions
WHERE rating <= 2
  AND created_at >= NOW() - INTERVAL '30 days'
ORDER BY created_at DESC
LIMIT 50;

-- ツール使用パターン
SELECT
    tool_call->>'name' as tool_name,
    COUNT(*) as call_count,
    ROUND(AVG((tool_call->>'latency_ms')::int), 0) as avg_latency_ms
FROM ai_interactions,
     jsonb_array_elements(tool_calls) as tool_call
WHERE created_at >= NOW() - INTERVAL '30 days'
GROUP BY tool_call->>'name'
ORDER BY call_count DESC;

-- 時間帯別の利用パターン
SELECT
    EXTRACT(HOUR FROM created_at) as hour,
    COUNT(*) as sessions,
    ROUND(AVG(rating), 2) as avg_rating
FROM ai_interactions
WHERE created_at >= NOW() - INTERVAL '30 days'
GROUP BY EXTRACT(HOUR FROM created_at)
ORDER BY hour;
```
