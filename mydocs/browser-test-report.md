## 5. e2eテスト実装の推奨優先順位

### Phase 1（最優先）

1. 認証フロー（ログイン/ログアウト）
2. 基本的なCRUD操作
   - 目標作成→マイルストーン作成→タスク作成
   - タスク完了
   - ノート作成・編集
3. タイムブロック操作
   - 予定追加
   - 実績追加

### Phase 2（重要）

1. フィルター・検索機能
2. ドラッグ&ドロップ操作
3. 日付ナビゲーション
4. 一括操作

### Phase 3（補完）

1. テーマ切り替え
2. 分析レポート表示
3. AI振り返り機能
4. エッジケース
