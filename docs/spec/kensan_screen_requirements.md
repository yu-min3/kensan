## 2. 画面詳細要件

### S01: ログイン/設定画面

**目的**: 初期セットアップとClockify連携設定

**表示要素**:
- Clockify APIキー入力フィールド
- 接続テストボタン
- ワークスペース選択（API接続後）
- タイムゾーン設定
- テーマ設定（ライト/ダーク）
- データエクスポート/インポート

**アクション**:
- APIキー保存（localStorage/IndexedDB）
- 接続テスト実行
- 設定保存

**目的**: 1日の計画を立てる。「今日何をやるか」「いつやるか」を明確にする。

**表示要素**:

```

│  │  ------┃----------------------------------------------│ │

│  │  16:00 ┃                                              │ │
│  │  ------┃----------------------------------------------│ │
│  │  16:30 ┃ 技術ニュースチェック（定期）       15min     │ │
│  │  17:00 ┃ 英語学習（定期）                   30min     │ │
│  └──────────────────────────────────────────────────────┘ │
│                                                            │
│  📋 未スケジュールのタスク                                 │
│  ┌──────────────────────────────────────────────────────┐ │
│  │ ☐ PCA試験勉強 - PromQL                      🏷️ GK    │ │
│  │ ☐ OSS Issue対応                             🏷️ OSS   │ │

**機能要件**:
- **タイムブロック計画**: 時間帯とタスクを紐づけて1日の計画を作成

  - タスクをドラッグ&ドロップで配置
  - 定期タスクも時間指定可能
- 前日夜に作成した計画を表示
- 定期タスクの自動表示（曜日フィルタ）
- タスクの並び替え（ドラッグ&ドロップ）
- タスクの追加・編集・削除
- Clockifyタイマー開始（タスク選択→開始）
- 目標タグごとの週間進捗表示
- 予定時間の合計表示

**データソース**:
- Clockify API: プロジェクト、タスク
- IndexedDB: タイムブロック計画、選択したタスク、定期タスク

**機能要件**:
- **計画 vs 実績比較**: タイムライン上で計画と実績を並べて表示
  - 計画通り / 超過 / 予定外 をアイコンで表示
  - 差分時間の表示
- 今日の時間記録をタイムライン表示
- 計画達成率・予定外作業時間の集計
- 目標タグ別の時間配分（円グラフ/棒グラフ）
- 完了/未完了タスクの確認
- 未完了タスクを翌日に繰り越し
- 簡易メモ入力（学習記録への導線）
- **明日のタイムブロック作成**: 翌日の時間割を作成
- 学習記録・日記作成への導線

**データソース**:
- Clockify API: 今日の時間記録
- IndexedDB: タイムブロック計画、タスク完了状態、メモ

### 4.1 タイムブロックのデータ構造

```typescript
interface TimeBlock {
  id: string;
  date: string;           // YYYY-MM-DD
  startTime: string;      // HH:mm
  endTime: string;        // HH:mm
  taskId?: string;        // Clockifyタスク or 定期タスク
  taskName: string;
  projectId?: string;
  goalTag?: string;
  isRoutine: boolean;     // 定期タスクかどうか
  createdAt: Date;
  updatedAt: Date;
}

interface DailyPlan {
  date: string;           // YYYY-MM-DD
  timeBlocks: TimeBlock[];
  createdAt: Date;
  updatedAt: Date;
}
```
