# Chrome モード フロントエンドテストプロンプト

Claude Code の Chrome モード（`--browser`）でフロントエンドを網羅的に操作し、エラーを検出するためのプロンプト。

## 使い方

```bash
# 1. アプリを起動（フロント + バックエンド + DB + Observability）
make rebuild

# 2. Claude Code を Chrome モードで起動し、以下のプロンプトを投入
```

---

## プロンプト

```
あなたはKensanアプリケーション（localhost:5173）のフロントエンドQAテスターです。
全ページ・全機能を操作してエラーがないか調査してください。

## 前提
- アプリは `make rebuild` で起動済み（フロント・バックエンド・DB・Observability全て含む）
- 開発サーバー: http://localhost:5173
- テストユーザー: test@kensan.dev / password123
- Grafana: http://localhost:3000（認証不要、Service Overviewダッシュボード）

## テスト手順

### Phase 1: ログインとデイリーページ
1. http://localhost:5173 にアクセス
2. test@kensan.dev / password123 でログイン
3. デイリーページ（ホーム）の表示確認
   - タイムブロックタイムライン表示
   - タスク一覧表示
   - DailySummaryセクション表示

### Phase 2: タイムブロック操作
1. タイムブロックの新規作成（ダイアログから）
2. 既存タイムブロックのドラッグ＆リサイズ
3. タイムブロックの編集・削除

### Phase 3: ノート機能
1. /notes に遷移 → ノート一覧が表示されること
2. 新規ノート作成（/notes/new）
3. Markdownエディタでテキスト入力・保存
4. ノート編集画面（既存ノートをクリック）
5. ノートの削除

### Phase 4: タスク管理
1. /tasks に遷移 → プロジェクト・タスク一覧表示
2. タスク作成
3. タスクのステータス変更（完了/未完了）
4. RecurringTaskWidgetの表示確認

### Phase 5: アナリティクス
1. /analytics に遷移
2. 週次・月次サマリーの表示確認
3. グラフ/チャートの表示確認

### Phase 6: 設定
1. /settings に遷移
2. 設定項目の表示確認

### Phase 7: AIチャット
1. Ctrl+Shift+A でチャットパネルを開く
2. メッセージ送信
3. SSEストリーミングの動作確認
4. ActionProposal（書き込みアクション承認）が出た場合の動作

### Phase 8: サイドバー・ヘッダー
1. サイドバーの各ナビゲーションリンクをクリック
2. ヘッダーのUI要素を操作

## エラー検出方法

### 操作中
- ブラウザコンソール（DevTools）を常に監視
- コンソールに出力されるエラー・警告を全て記録
- ネットワークタブで失敗したAPIリクエスト（4xx/5xx）を記録
- UIのレンダリング崩れやフリーズも報告

### 操作完了後
- http://localhost:3000 のGrafanaを開く
- 「Kensan Service Overview」ダッシュボードでError Rateを確認
- エラーがあればTempoでトレースを追跡して詳細を報告

## レポート形式

各ページ/機能ごとに以下を報告：
- ✅ 正常動作
- ❌ エラー発見（エラー内容、再現手順、コンソールログ/ネットワーク情報）
- ⚠️ 警告（動作はするが問題の兆候あり）

最後にGrafanaから確認したバックエンドエラー情報も付記すること。
```
