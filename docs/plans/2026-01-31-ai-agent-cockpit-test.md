# AI Agent Cockpit - Phase 1 テスト手順

**対象**: フロントエンド（MSWモック）の動作確認
**前提**: `VITE_ENABLE_MSW=true npm run dev` でdev serverが起動済み
**URL**: http://localhost:5173

> **トークン節約の注意**:
> - スクリーンショットは必要最小限に。全テスト項目ごとに撮る必要はない
> - 1つのテストグループ完了時に1枚撮れば十分
> - DOMの全文取得は不要。必要な要素の存在確認のみ行うこと
> - 失敗時のみ詳細なスクリーンショットやDOM確認を行う
> - テスト結果は「OK/NG + 簡潔な説明」で報告すること

## 1. チャットパネルの開閉

### 1-1. ボタンによる開閉
1. Headerの右側にBotアイコン（ロボットのアイコン）ボタンがあることを確認
2. クリック → 右側にチャットパネル（幅380px程度）がスライドイン
3. パネルヘッダーに「AI Assistant」と表示
4. パネル内に「何かお手伝いしましょうか？」のプレースホルダー
5. 再度Botアイコンをクリック → パネルが閉じる

### 1-2. ×ボタンで閉じる
1. パネルを開く
2. パネル右上の×ボタンをクリック → 閉じる

### 1-3. キーボードショートカット
1. Ctrl+Shift+A → パネルが開く
2. もう一度 Ctrl+Shift+A → パネルが閉じる

---

## 2. 読み取り系: タスク一覧表示

1. パネルを開く
2. 入力欄に「タスク見せて」と入力してEnter
3. 確認項目:
   - ユーザーメッセージが右寄せで表示
   - 「タスクを確認しますね。」とAIメッセージ（左寄せ、Botアイコン付き）
   - 「タスクを確認中...」のローディングインジケーター（一瞬表示されて消える）
   - 未完了タスクの一覧がリスト形式で表示

---

## 3. 書き込み系: 予定提案 → 承認/却下

### 3-1. 提案表示
1. 入力欄に「今日の予定立てて」と入力してEnter
2. 確認項目:
   - ツール実行インジケーター表示 → 消える
   - 「以下のスケジュールを提案します：」のメッセージ
   - 「提案されたアクション」カードが表示
   - チェックボックス付きのアクション一覧（時間帯 + タスク名）
   - 「承認」「却下」ボタン

### 3-2. 却下
1. 「却下」ボタンをクリック
2. 「提案をキャンセルしました。」のメッセージが表示

### 3-3. 提案 → 承認
1. 再度「予定立てて」と入力
2. 提案が表示されたら「承認」ボタンをクリック
3. ツール実行インジケーター → 「〇件のタイムブロックを作成しました。」メッセージ

---

## 4. 汎用チャット

1. 「こんにちは」と入力してEnter
2. 「了解しました。」から始まる汎用応答が表示されること

---

## 5. 新しい会話

1. パネルヘッダーの＋ボタンをクリック
2. メッセージ履歴がクリアされ、プレースホルダーに戻ること

---

## 6. レイアウト確認

1. パネル開閉時にメインコンテンツ（DailyPage）の幅が動的に変化すること
2. パネルが開いた状態でサイドバーのナビゲーションが正常に動作すること（例: タスク管理ページに遷移）
